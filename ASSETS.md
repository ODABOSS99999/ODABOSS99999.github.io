# Asset and license record

The library scene uses original CSS and SVG artwork in `src/Scene.tsx` and `src/Objects.tsx`, with the original SVG mark in `public/mark.svg`. Wood grain, metal, paper, lighting, shadows, and empty frames are procedural decoration. They are not owner photographs or completed engineering projects. No stock photography, premium assets, third-party models, or generated portfolio images are included.

`src/audio.ts` creates original procedural audio with the browser Web Audio API. There are no downloaded recordings, paid audio services, or runtime AI calls. No third-party sound attribution is required.

Fonts are bundled and served locally by Vite; visitors need no font CDN request. Preserve the bundled font licenses when distributing builds. OFL allows use and redistribution with the license and its conditions; no font files have been renamed or modified here.

No portfolio photographs, portrait, publication thumbnails, or engineering images have been supplied yet. Future entries should record: file path, creator, original source URL or owner-supplied provenance, license/permission, required attribution, and modifications. Keep source originals intact and outside deployed `public/`. Do not assume social media availability grants reuse rights.

Application dependencies are recorded with exact installed versions in `package-lock.json`; their licenses remain in their installed packages. This file does not impose a new license on the owner's photographs or personal material.
